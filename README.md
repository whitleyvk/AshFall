# ASHFALL

**ASHFALL** - независимый русскоязычный High RP проект на базе [Space Station 14](https://github.com/space-wizards/space-station-14).

Станция принадлежала **Ashen Industrial**. После банкротства компании эвакуация и снабжение прекратились, а часть экипажа была помещена в длительный криосон. Спустя годы автоматика пробуждает их, когда дальнейшее поддержание криокамер становится небезопасным.

Проект находится в активной разработке.
