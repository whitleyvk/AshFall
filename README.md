# ASHFALL

**ASHFALL** - русскоязычный High RP сервер на базе [Space Station 14](https://github.com/space-wizards/space-station-14).

2291 год. После банкротства корпорации **Ashen Industrial** станция осталась без снабжения и связи с внешним миром. Забытый экипаж годами находился в криосне, пока аварийный сбой автоматики не вызвал экстренное пробуждение.

Основа геймплея - выживание на разрушающемся объекте: ремонт изношенных отсеков, дефицит базовых ресурсов, исследование заброшенных отделов, выходы в открытый космос и взаимодействие внутри изолированного коллектива.

Каждый раунд - новая история со своими персонажами, вводными и уникальной конфигурацией станции, собранной из разных модулей и комнат.

Проект в разработке.
