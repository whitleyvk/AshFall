# Implementation roadmap

1. **Bootstrap and safe vertical slice (implemented):** pinned hard fork, provenance, whitelist development preset,
   technical Extended, deterministic Degradation profile, recoverable variation passes, and selector tests.
2. **Station contract:** one modular 7–40 player map; protected spawn/recovery paths; degradation zones and target
   markers; power, atmosphere, communications, and production fault packs with validation.
3. **Recovery loop:** fault completion detectors, station condition metrics, Stabilize → Restore → Rebuild → Aftermath
   pacing, curated shortages, and station-bound salvage magnet wrecks whose rewards answer the selected manifest.
4. **High RP layer:** explicit trust whitelist, round-type preferences plus curator selection, records and affiliations,
   soft job competencies, provocateur opt-ins, motivation/red-line briefings, and narrative round summaries.
5. **Aggressive reduction:** remove unselected modes and events, redundant maps and roles, unused prototypes and assets,
   Frontier-like ship loops, broad catalogs, and upstream deployment/branding infrastructure in build-green batches.
6. **Identity and persistence:** ASHFALL visual identity, Ashen Industrial interfaces where they make sense in-world,
   compact between-round outcome ledger, and resource modifiers; never serialize the live station grid as campaign state.

Exit criteria for a Degradation alpha: the same seed produces the same manifest; incompatible faults cannot coexist;
protected areas remain safe; every required repair input has a reachable source; recovery never forces an automatic
round end; and administrators have a logged recovery injection for genuinely catastrophic states.
